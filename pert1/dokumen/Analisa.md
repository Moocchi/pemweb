- What: Sebuah platform online yang berisi informasi, layanan, atau konten yang dapat diakses melalui internet.

- Why: Untuk menyediakan informasi, mempromosikan produk/layanan, atau sebagai sarana komunikasi dan transaksi.

- Who: Dikembangkan oleh developer, desainer, dan konten creator, serta ditujukan untuk pengguna internet.

**SWOT**

**Strengths:**

- Mudah diakses dari mana saja.

- Dapat menampilkan informasi secara visual menarik.

- Fleksibel dalam pembaruan konten.

**Weaknesses:**

- Membutuhkan pemeliharaan rutin.

- Rentan terhadap serangan keamanan.

**Opportunities:**

- Meningkatkan jangkauan bisnis secara global.

- Integrasi dengan teknologi baru (AI, IoT).

**Threats:**

- Persaingan tinggi di dunia online.

- Perubahan algoritma mesin pencari (SEO).


## **2. HTML**

HTML (`HyperText Markup Language`) adalah bahasa markup standar yang digunakan untuk membuat struktur dan konten halaman web. HTML terdiri dari elemen-elemen (seperti tag `head`, `body`, `p`, `img`) yang mendefinisikan bagaimana konten ditampilkan di browser. HTML bekerja bersama CSS (untuk styling) dan JavaScript (untuk interaktivitas) untuk membangun website yang dinamis.

**5W1H**

- What: Bahasa markup untuk membuat struktur halaman web.

- Why: Untuk mendefinisikan konten dan layout halaman web.

- Who: Digunakan oleh web developer dan desainer.

- When: Digunakan saat membangun atau mengupdate halaman web.

- Where: Dijalankan di browser pada perangkat apa pun.

- How: Dengan menulis kode HTML menggunakan teks editor atau IDE.

**SWOT**

**Strengths:**

- Mudah dipelajari dan digunakan.

- Didukung oleh semua browser modern.

**Weaknesses:**

- Terbatas dalam fungsionalitas tanpa CSS dan JavaScript.

- Tidak cocok untuk aplikasi kompleks sendirian.

**Opportunities:**

- Integrasi dengan teknologi web modern (WebAssembly, PWA).

- Dukungan untuk aksesibilitas dan SEO.

**Threats:**

- Perubahan standar web yang cepat.

- Persaingan dengan framework modern (React, Angular).

## **3. Docker**

Docker adalah platform open-source yang digunakan untuk mengembangkan, mengemas, dan menjalankan aplikasi dalam lingkungan terisolasi yang disebut container. Container memungkinkan aplikasi berjalan secara konsisten di berbagai lingkungan (development, testing, production) tanpa terpengaruh oleh perbedaan konfigurasi sistem. Docker memudahkan proses deployment dan scaling aplikasi.

**5W1H**

- What: Platform untuk mengemas dan menjalankan aplikasi dalam container.

- Why: Untuk memastikan aplikasi berjalan konsisten di berbagai lingkungan.

- Who: Digunakan oleh developer, DevOps engineer, dan perusahaan IT.

- When: Digunakan selama siklus pengembangan dan deployment aplikasi.

- Where: Dapat dijalankan di berbagai sistem operasi (Linux, Windows, macOS) dan lingkungan cloud.

- How: Dengan membuat image Docker dan menjalankannya sebagai container.

**SWOT**

**Strengths:**

- Konsistensi lingkungan pengembangan dan produksi.

- Ringan dan cepat dibanding virtual machine.

**Weaknesses:**

- Kurva belajar yang curam untuk pemula.

- Manajemen container yang kompleks untuk skala besar.

**Opportunities:**

- Meningkatkan efisiensi CI/CD pipeline.

- Adopsi luas di industri cloud-native.

**Threats:**

- Persaingan dengan platform container lain (Kubernetes, Podman).

- Masalah keamanan jika tidak dikonfigurasi dengan benar.
